## 2. 业务目标

将分散的模型搜索/下载/引擎/显存/模型池功能整合到统一前端管控面板，实现**搜索→下载→校验→加载→推理**全流程可视化。

**目标用户**: 管理员/运维人员
**核心痛点**: 前端功能碎片化、引擎信息不直观、下载缺乏实时性、显存不够醒目

## 6. 代码现状

大部分功能已有基础实现(8个页面、12个composables、15+个API方法)，本次重点是**UI重设计+功能完善+TS类型修复**。

### 关键缺口
- **引擎配置编辑UI**: API存在但无前端UI
- **SGLang/llama.cpp专项指标**: 不在Dashboard展示
- **搜索高级过滤器**: 只有基础排序
- **模型池统计概览**: 无总大小/状态分布卡片
- **下载→池→加载无缝UX**: 流程衔接不够顺畅
- **Agent图片上传**: UI不支持(后端supports_images已定义)

### 代码风险
- ModelManagement.vue已达3791行,需拆分
- useGPUMemory composable的Ref模板访问需解构才能正确TS推导
